# Java Web Application Evolution: Servlets to Spring Boot

## 1. Project Overview

### Objective

Understand the evolution of Java dynamic web application development, starting from raw Java Servlets and gradually progressing to modern Spring Boot applications.

The goal is not just to learn frameworks but to understand:

- Why each technology was introduced.
- What problems it solved.
- How web applications worked before frameworks existed.
- How each layer interacts internally.
- What Spring and Spring Boot automate behind the scenes.

### Learning Approach

Build one Banking Management Application incrementally.

Each phase introduces a new concept or technology, extends the existing application, and compares the new approach with the previous implementation.

**Core principle: Understand the problem first, implement the solution manually, and then learn how frameworks solve the same problem.**

## 2. Application Scope

The Banking Management System will gradually support:

1. Customer registration and management.
2. Bank account creation and management.
3. Account balance enquiry.
4. Fund transfers.
5. Transaction history.
6. User authentication.
7. Role-based authorization.
